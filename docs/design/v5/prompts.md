# V5 — Prompts para gerar imagens (ChatGPT)

*As 6 imagens de Artists e Experiences e a opcional do About já foram geradas pelo owner a 24/10/2026
(`assets.md` §3). Este ficheiro guarda os prompts para regenerar, variar ou acrescentar.*

## Como usar

1. Abrir **uma só conversa** no ChatGPT para a série inteira (mantém o tom).
2. Anexar como **referência de estilo** (opcional): `research/refs/ref-light-video-still.jpg` e, se
   quiser, `ref-tone-157.jpg` / `ref-tone-024.jpg` (fotografias do próprio owner — decisão dele).
3. Se anexar referências, colar primeiro:
   ```
   Use the attached images only as a reference for light, colour grade and film texture. Do not reproduce the people, faces or places in them.
   ```
4. Gerar **a cores** (o site pode derivar o P&B). Formato vertical 2:3 (1024×1536, o máximo do ChatGPT).
5. Se uma imagem sair diferente das outras: *"match the light and colour grade of the previous image"*.

Regras comuns (já dentro de cada prompt): sem rostos reconhecíveis, sem texto legível, sem logótipos,
sem marcas de água, sem ecrãs com interface; terço superior calmo para tipografia.

## Editar uma fotografia real (hipótese aprovada)

Para colocar uma fotografia real do casal num cenário diferente, anexar a fotografia e pedir, por exemplo:
```
Keep the two people exactly as they are (pose, clothing, light on them, black-and-white film look). Replace only the background with [describe the new setting], matching the perspective, light direction and film grain of the original. Do not change their faces or bodies. Portrait orientation, same framing.
```
Rever sempre o resultado a 100 % (mãos, contornos, grão) antes de usar.
