O botão do menu

Escolhido (README #67): no telemóvel, três traços de comprimentos diferentes, sem palavra (100, 70 e 85 %, como no site original), que viram X ao abrir; no desktop fica a palavra Menu, aqui com os mesmos três traços ao lado. Carrega no botão dos quadros em baixo para o ver.

Sem palavra, o botão diz Menu aos leitores de ecrã (aria-label) e mantém 44 px de toque, maior do que o desenho. Se no desktop preferires os dois traços de agora com a palavra, troca-se só o desenho.

↳

O clique no nome

Aqui com a variante A. O clique sobe ao topo e a entrada corre outra vez: a hora, CHAPTER ONE com o vídeo, e o fim da entrada (E4) com as lâminas. Qualquer gesto salta para o fim. No topo a barra mostra só o nome, porque ainda não há secção.

Com reduced motion ou sem JavaScript, o nome é só uma ligação para o topo, já no E4.
