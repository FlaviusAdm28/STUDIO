## Porque não foi promovido

1. **Um push para `master` publica o site.** A API de deployments do GitHub mostra que o Vercel cria um
   deployment de **Production** para cada commit de `master` (`133f080` a 2 de outubro, `ce463dd` a 28 de
   setembro) e um **Preview** para cada commit de `v2` (incluindo `acd2333`, hoje, estado `success`). A
   autorização desta ronda abrange a publicação Git em `master` e exclui explicitamente o deploy. As duas
   coisas não são separáveis com a configuração actual.
2. **Os contactos publicados são um marcador de posição.** `content/site.ts` (linha 1312) tem
   `+351 910 000 000`, e o próprio comentário do ficheiro (1274–1276) diz que é *"a reserved pattern
   rather than a line anybody answers"*. As ligações de WhatsApp (`wa.me/351910000000`) e Telegram
   (`t.me/+351910000000`) são compostas a partir dele. O endereço `hello@chapterone.com` está no site;
   o domínio tem registos MX (Google), mas **não foi verificado quem o detém nem se a caixa existe**.
   Para um site cujo objectivo é receber pedidos, isto é bloqueante. Estes mesmos valores já estão na
   produção actual (`133f080`).

- Todas as medições de gesto são sintéticas, uma passagem por cenário.
